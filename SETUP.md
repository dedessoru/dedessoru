# DEDESSORU / 08 — Setup

1. Create a **public** GitHub repository named exactly **`dedessoru`** under the account **`dedessoru`**. If the profile repository already exists, use it.
2. Upload `README.md` and the full `assets/` directory to the repository **root**. Do not nest them inside an extra `dedessoru-profile-v3/` folder.
3. Open `https://github.com/dedessoru` to view it. Toggle GitHub light/dark appearance to verify the banner and signature.
4. Pin `eidolon` and other repositories only when their source and README are ready to show.
5. If the profile feels too animated, remove the `<p align="center">` block containing `signal-dark.gif` / `signal-light.gif` from `README.md`.
6. The HTML `<details>` elements are clickable native disclosure sections in GitHub Markdown. The artwork is stored locally, so no image-stat API keys or third-party endpoints are needed.
